# Compiler Design Lab

This repository contains programs and implementations developed as part of the **Compiler Design Laboratory**.

The programs cover the major phases and concepts involved in compiler construction, including **lexical analysis, syntax analysis, intermediate code generation, code optimization, and related compiler techniques**.

## 📚 Topics Covered

- Lexical Analysis
- Regular Expressions and Pattern Matching
- Lex / Flex Programs
- Context-Free Grammars
- Yacc / Bison Programs
- Syntax Analysis
- Parsing Techniques
- Symbol Tables
- Intermediate Code Generation
- Three Address Code
- Code Optimization
- Constant Folding
- Constant Propagation
- Dead Code Elimination
- Common Subexpression Elimination
- Code Generation

## 🛠️ Technologies Used

- **C**
- **Lex / Flex**
- **Yacc / Bison**
- **GCC**
- **Linux / WSL**
